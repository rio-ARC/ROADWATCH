# Demo Script

1. Start API and frontend.
2. Open `/report`.
3. Click **Run AI triage** and point out damage type, severity, confidence, and routing.
4. Submit the complaint, then open `/offline` to show deferred queue behavior.
5. Open `/map` to show complaint markers, heat radius, filters, and nearby issues.
6. Open `/dashboard` to show severity distribution, authority response time, contractor performance, and budgets.
7. Open `/chat` and ask: “Who is responsible for the pothole near Velachery MRTS?”

Key message: RoadWatch is not a chatbot wrapper. It is a civic operating layer where AI assists evidence analysis and explanation while auditable rules handle routing and public accountability.
